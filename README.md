# Country Explorer 🌎
A online service that offers data about nations worldwide is the REST Countries API.
Information including a nation's name, population, capital city, currency, language, and more can be queried by users.
Because the data is in a JSON format, developers can easily incorporate it into their applications.
A web application called the REST Countries API using React enables users to look up and browse data about nations worldwide.
The application is a cutting-edge and effective way to use the REST Countries API because it was developed with React and React Hooks.
Use client-side routing with React Router to move between pages.

## Features
- All screens responsive
- Search filter
- Region / Continents filter


## 🔧Tech Used
- React / Vite
- React Router
- React Hooks
